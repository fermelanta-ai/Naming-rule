## 4. 菌株ID

```
MS<数字>
```
`MS686` `MS705` `MS707` `MS708` `MS823` `MS910` `MS1031` など。
複数株は `-` 連結（`MS686-MS705`）。4株以上は代表株のみ書き、全リストは中身へ。

菌株マスタ: `03.研究開発/DB/strain_information/`
