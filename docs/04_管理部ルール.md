# 04. 管理部ルール

前提: [`01_全社共通ルール.md`](01_全社共通ルール.md) を満たしたうえで、以下を適用します。

## 0. 方針

管理部は**社内で最も優れた命名体系（契約書）と、最も無規律な領域（経理直下の証憑）が同居**しています。

- 契約書命名 `20260212_CONFIDENTIAL DISCLOSURE AGREEMENT_BBGI Public Company Limited_A20260019.pdf`
  は全社テンプレートに昇格させます。
- 一方、経理直下の証憑は**電子帳簿保存法の検索要件を満たしていません**。
  これは整理整頓ではなく、税務調査時のリスクです。最優先で対応します。

---

## 1. 証憑（請求書・領収書・支払明細）— 最優先

### 1.1 構文

```
YYYYMMDD_<取引先>_<書類種別>_<税込金額>[_<管理番号>].<拡張子>
```

```
20260714_日本曹達_請求書_97588.pdf
20260703_NEDO_概算払請求書_86668441.pdf
20260706_北陸電気工事_請求書_400562.pdf
20260729_NTTファイナンス_振込明細_517645.pdf
```

- **金額はカンマなし・税込・円単位の数字のみ**（カンマは禁止文字）。
  現行 `20260703_NEDO概算払請求書_86,668,441.pdf` はカンマを含むため要修正。
- 外貨建ては `USD12500` のように通貨コードを前置。
- 取引先は§4の取引先名辞書に従う（法人格は省略）。

### 1.2 なぜ必須か

電子帳簿保存法（電子取引データ保存）は、**取引年月日・取引金額・取引先**の3項目で
検索できる状態を求めます。ファイル名に3項目を含めるのが最も簡便な対応方法です。

現在 `02.経理` 直下にある以下は、いずれも要件を満たしません。

```
0800062279_0097081713_0000007700465352.pdf   ← 業者の管理番号のみ
202607021745527137.zip                        ← タイムスタンプのみ
file_2359.pdf / print.pdf                     ← 内容不明
FEDEX0707-1.pdf / FEDEX0707-2.pdf             ← 年なし
IMG_6157.jpeg / IMG_6158.jpeg                 ← スマホ撮影のまま
NTT振込0729.pdf                                ← 年なし・金額なし
PP水道料金.jpg / クルーズ.pdf / 地方税延滞金.pdf ← 日付・金額なし
海外送金取引明細書SUB.pdf
振込明細【振込・振替】7月分.pdf                 ← 【】と年なし
経費発生調書　PMS　PDF.pdf                      ← 全角スペース
請求書_HS1093.002_ファーメランタ株式会社 御中.pdf ← 日付・金額・取引先が不明
```

### 1.3 受領時のルール

**業者が発行した PDF は、受領した時点でリネームします。**
（研究開発部の機器生データとは扱いが逆です。理由: 証憑は法令上の検索要件が優先されるため）

保存フローは以下に固定します。

```
02.経理/01.支払・購買管理/<YYYY年度>/<MM月>/
  20260714_日本曹達_請求書_97588.pdf
```

`02.経理` 直下に直接ファイルを置かないでください。現在30件以上が直下に滞留しています。

## 2. 契約書 — 全社テンプレート

### 2.1 構文（現行を正式ルール化）

```
YYYYMMDD_<契約書正式名称>_<相手先正式名称>_<契約管理番号>.<拡張子>
```

```
20260212_CONFIDENTIAL DISCLOSURE AGREEMENT_BBGI Public Company Limited_A20260019.pdf
20250903_秘密保持契約書_神戸天然物化学_A20260010.pdf
```

- 契約書は**唯一、法人格を含む正式名称を使う場所**です（法的正確性を優先）。
- 語順は「日付＿契約名＿相手先＿管理番号」。
  現行 `20250903_秘密保持契約書_神戸天然物化学_A20260010.pdf` はこの順で正しい形です。

### 2.2 契約管理番号

```
<区分1文字><西暦4桁><連番4桁>
```

区分記号は `10.契約` のフォルダ名と一致させます。

| 区分 | フォルダ | 内容 |
|---|---|---|
| `A` | `A_NDA` | 秘密保持契約 |
| `B` | `B_ベンダー基本契約, 業務委託契約` | ベンダー基本・業務委託 |
| `C` | `C_PoC, 共同研究, ライセンス（in, out）` | PoC・共同研究・ライセンス |
| `D` | `D_クライアント製造, 販売` | 製造・販売 |
| `E` | `E_人材紹介` | 人材紹介 |
| `Y` | `Y_投資契約（金融系契約）` | 投資・金融 |
| `Z` | `Z_その他` | その他 |

台帳: `10.契約/契約管理台帳.xlsx`
※ 現行 `契約管理台帳_20260902.xlsx` は日付サフィックスを外します（継続更新の台帳のため）。

### 2.3 契約フォルダの構造（全社標準）

```
10.契約/<区分>_<種別>/<相手先正式名称>/
├── 00_NDA/
├── 10_MOU/
├── 20_Support Letter/
├── 30_共同研究/
└── 99_参考資料/
```

連番は10刻み。BBGI の既存構造がそのまま標準です。

### 2.4 未締結の表し方

現行の `[未] Profluent Bio Inc` `[未]Bioforge` `[未？] シーエムプラス` は
角括弧接頭辞で三様に揺れており、五十音／アルファベット順ソートも壊しています。

```
✗ [未] Profluent Bio Inc
✗ [未]Bioforge
✗ [未？] シーエムプラス
○ 10.契約/A_NDA/99_交渉中/Profluent Bio Inc/
```

締結したら `99_交渉中/` から相手先フォルダごと上位へ移動します。

## 4. 取引先名の扱い

事業開発部の取引先名辞書を**管理部も共用**します（二重管理しない）。
ただし契約書の締結版のみ、正式名称（法人格を含む）を使います。

| 用途 | 表記 |
|---|---|
| 証憑・議事録・社内資料 | 辞書の略称（`日本曹達`） |
| 契約書の締結版ファイル名 | 正式名称（`日本曹達株式会社`） |
| 契約フォルダ名 | 正式名称（`BBGI Public Company Limited`） |

## 5. 人事労務・機微情報

### 5.1 氏名をファイル名に入れない

```
✗ 06.人事労務/03.社員履歴書/山田太郎_履歴書.pdf
○ 06.人事労務/03.社員履歴書/20260401_履歴書_E0123.pdf
```

`E<4桁>` は社員番号。氏名と社員番号の対応表は
`06.人事労務/01.人事/社員マスタ.xlsx` にアクセス制限付きで保持します。

### 5.2 ID・パスワードをファイル名に入れない

```
✗ 20260724_NTTファイナンス　PP電気料金口座振替案内とIDPW_表優佳.pdf
○ 20260724_NTTファイナンス_口座振替案内_PP電気.pdf
```

### 5.3 社外の個人名

```
✗ 20260728_テクニカルセミナー講演依頼書・承諾書（ファーメランタ株式会社 本吉創様本人用）.doc
○ 20260728_講演依頼書_島津製作所_Motoyoshi.doc
```

社内メンバーは姓のみローマ字、社外の個人は原則入れず、必要なら姓のみ。

## 9. 管理部だけの追加禁止事項

| 禁止 | 理由 |
|---|---|
| 業者発行名のまま証憑を保存 | 電子帳簿保存法の検索要件を満たさない |
| 金額にカンマを入れる | 禁止文字。`86,668,441` → `86668441` |
| `02.経理` 直下へのファイル直置き | 年度／月フォルダへ |
| `★` `◆` `【】` `　`（全角スペース） | 全社共通ルール違反 |
| ファイル名への氏名フルネーム・ID・パスワード | 権限外への露出リスク |
| フォルダ番号の重複 | 並び順と参照が壊れる |
| 継続更新の台帳への日付サフィックス | 版が増殖する。SharePoint 履歴を使う |
