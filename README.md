## 3行でわかる全社共通ルール

```
YYYYMMDD_<第1キー>_<第2キー>[_補足][_vNN].拡張子
```

1. **日付は先頭・8桁固定**（`20260728`）。6桁・スペース区切り・`@` 区切りは禁止。
2. **区切りは半角アンダースコア `_` のみ**。半角/全角スペース、`＿`、`（）`、`【】`、`★◆`、`&`、`#` は使わない。
3. **版は `_v01` `_v02` `_vF`**。`最新` `修正済み` `コピー` `(1)` `new/old` は禁止。SharePoint のバージョン履歴を優先し、社内案は原則バージョンを付けない。

第1キー・第2キーの中身は部門ごとに定義（各部門ルール参照）。
